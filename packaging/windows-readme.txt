BOOKWYRM FOR WINDOWS
A library, reader and editor for your PDFs, kept by a silver dragon.


TO START

1. Unzip this folder somewhere it can stay, such as Documents.
   (Right-click the zip and choose "Extract All". Do not run it from inside the
   zip, and keep everything in the folder together.)

2. Open the folder and double-click "Bookwyrm" (the one with the dragon icon).

   If Windows says "Windows protected your PC", click "More info", then
   "Run anyway". Windows shows this for any program that is not from a big
   publisher.

3. To find it easily next time, right-click "Bookwyrm" and choose "Pin to Start",
   or "Show more options" > "Send to" > "Desktop (create shortcut)".

Nothing needs installing, and nothing is added to Windows outside this folder.


IF SOMETHING GOES WRONG

Bookwyrm is new on Windows, so a hiccup is possible, and a report from you is
exactly what is needed to fix it. Send back the file "bookwyrm.log" from the
"Bookwyrm Library" folder inside your user folder (for example
C:\Users\YourName\Bookwyrm Library), with a line about what you were doing.
It contains nothing from your PDFs.


USING IT

- Click "Add Tomes" to bring PDFs in. Bookwyrm keeps its own copies in
  "Bookwyrm Library" in your user folder; your original files are never changed.
- Organise them into Bookcases, Shelves and Sets, by dragging.
- Double-click a tome to read it. The quill button opens the Scriptorium for
  highlighting, notes, filling in forms and editing.
- Hover over any button to see what it does and its keyboard shortcut.
- Help > About lists everything Bookwyrm is built with.


TO REMOVE IT

Delete this folder. If you also want the copies of your PDFs gone, delete the
"Bookwyrm Library" folder in your user folder.
